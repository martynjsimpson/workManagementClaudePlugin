# Security Policy

## Supported versions

Only the latest released version is supported. Enable auto-update for this marketplace
(`/plugin` → **Marketplaces** → **Enable auto-update**), or run `/plugin marketplace update`
and `/plugin update` to stay current.

## Reporting a vulnerability

This plugin's commands and skills run with your own Claude Code permissions and can read,
write, and run git/gh operations on your repository. If you find something that could be
tricked into an unintended action — for example, a way to make a command write outside its
declared scope, or an instruction a malicious file could hijack — please report it privately
rather than opening a public issue.

Email: martynjsimpson@gmail.com

Include what you found, the plugin version, and steps to reproduce if you can. I'll
acknowledge within a few days and let you know once a fix ships.
